Название датасета: Yelp Dataset
Ссылка на датасет: `https://www.kaggle.com/datasets/yelp-dataset/yelp-dataset/data?select=yelp_academic_dataset_user.json`

В работе использовались файлы `review.json`, `business.json`, `user.json`


## Запуск проекта

1. Скачать Yelp Open Dataset по ссылке выше.
2. Установить зависимости из `requirements.txt`.

```bash
python -m venv venv
```

```bash
source recsys_venv/bin/activate
```

```bash
pip install -r requirements.txt
```

3. Разместить файлы датасета в папке `data/`.
4. Открыть `experiments.ipynb` в Jupyter Notebook и выполнить ячейки.
